# 기억 서재 — 마리나라 엔진용 장기 기억 모듈

긴 롤플레이(수백~수천 턴)에서 캐릭터가 지난 일을 **사람처럼** 기억하게 해 주는 기억 모듈입니다.
지난 대화를 장면·사실·약속·감정으로 정리해 두었다가, 답변을 만들 때마다 지금 필요한 기억을 골라 프롬프트에 넣어 줍니다.

> **비공식 모듈입니다.** Marinara Engine 및 Pasta-Devs와 관련이 없고, 그쪽의 검토나 지원을 받지 않습니다.
> Marinara Engine **2.4.6 전용 호환 브랜치**입니다. 공식 2.4.6 서버를 직접 빌드해 실행하고 장부·장면·회상·말풍선 태그·기억 언어 흐름을 확인했습니다. [검증 범위](COMPATIBILITY.md)를 확인해 주세요.

지금 버전: **v0.15.0-marinara.2.4.6.85 (호환 베타)** · 변경 내역은 [CHANGELOG.md](CHANGELOG.md)

## 무엇을 하나요

- **직접 선택한 기억** — 채팅 메시지를 드래그하고 ‘기억으로 정리’를 누르면 선택한 부분만 별도로 정리합니다. 한눈에 화면에서 확인·삭제할 수 있습니다. 관련 낱말이 나올 때 회상하며, 원문이 바뀌면 자동 회상에서 제외됩니다.
- **방별 정리 방식** — 설정에서 주변 NPC·모브를 자세히 정리할지, 원문은 대사 위주·서술 위주·둘 다 중 무엇을 보존할지 고릅니다. 설정은 새로 정리하는 장면부터 적용되고, NPC·모브 자세히는 이름 없는 단역을 역할 이름으로 따로 기록합니다.

- **방을 지우면 기억도 영구 삭제** — 마리나라에서 방을 지우면(그룹 삭제·장면 방 버리기 포함) 그 방의 기억과 방별 설정도 함께 지워지며 되돌릴 수 없습니다. 이 기능 이전에 지운 방의 기억은 자동으로 지우지 않고, 설정 → ‘삭제된 방의 기억’에서 확인 후 직접 지울 수 있습니다.
- **잘려 저장된 대사 복구 · 도우미 채팅 숨김** — 0.11.48 이전에 따옴표가 어긋난 문단에서 조각으로 저장된 대사는 장면을 확인할 때 모델 호출 없이 원문 대사 전체(원문 + 번역)로 고쳐집니다(직접 고친 대사·장면은 그대로). 마리나라 내부 도우미 채팅(`internalAssistant`)은 방 목록에 나오지 않습니다(직접 기억을 켠 경우 제외).
- **대사 상대 추정은 그 자리에 있던 사람만** — 서술에 이름만 나온 사람(생각만 했거나 이야기에 오른 사람)은 추정 상대가 되지 않습니다. 새로 정리하는 장면은 사건마다 ‘그 자리에 있던 사람’을 저장해, 한 장면에서 장소가 둘로 나뉘어도 그 사건에 있던 사람만 후보로 봅니다. 이전 규칙으로 만든 ‘추정’ 상대는 ‘이어서 정리’ 때 한 번 다시 확인하며, 확실한 상대와 직접 고친 대사는 건드리지 않습니다.
- **글 속 표기 바꾸기(이름 정리)** — 이름을 합친 뒤 글(요약·사건·사실·챕터·할 일·생활)에 남은 옛 표기를 별칭마다 원하는 표기로 바꿀 수 있습니다. 미리 보기를 거치며 원문 대사·이름 칸·직접 고친 항목은 바꾸지 않고, 되돌리기가 됩니다.
- **분기 기억 이어받기** — 업데이트 후 새 분기를 만들면 원본에서 이미 정리된 기억과 방별 사용 설정을 분기 지점까지 자동으로 넘깁니다. 직접 고친 기억도 유지되며, 이후에는 방마다 독립적으로 갱신됩니다. 분기 지점을 걸치는 장면·장부 묶음은 다시 읽습니다. 아주 오래전 분기라 장부 복구 기록이 없으면 장면 기억은 넘기고 장부는 다시 정리합니다. 업데이트 전에 만든 분기는 자동으로 덮어쓰지 않습니다.
- **장면 기억** — 모델이 더 이상 원문으로 보지 못하는 지난 대화를 장면 단위로 정리합니다. 장면마다 작중 시간·장소·날씨·요약, 실제 대사(원문과 한국어 번역을 따로 저장하고 `"원문" (번역)` 한 형식으로 보여 줌), 인물마다 그 장면을 얼마나 기억하는지(다 기억함 / 흐릿함 / 기억 못 함)가 남습니다.
- **챕터와 큰 흐름** — 오래된 장면은 이야기 흐름이 끝나는 곳에서 끊어 챕터로 묶고, 챕터가 많이 쌓이면 오래된 챕터 여러 개를 다시 '큰 흐름'(A1, A2 …)으로 묶습니다. '지난 이야기 흐름'에는 큰 흐름이 맨 앞에 늘 들어가고 최근 챕터가 이어서 들어가, 아주 긴 이야기도 처음부터 지금까지의 줄기가 정해진 길이 안에 들어갑니다.
- **알게 된 사실** — 인물의 설정·과거·관계처럼 오래 가는 사실. 같은 주제로 쌓이면 자동으로 합칩니다.
- **아직 끝나지 않은 일** — 약속, 풀리지 않은 감정(원인과 풀리려면 필요한 것), 비밀과 단서, 기간이 있는 상태(휴가, 몸살 등), 미해결 일.
- **기한** — 마감·약속 날짜가 있는 일은 기한이 가까운 것부터 매번 넣고 "D-2", "3일 지남"처럼 작중 날짜로 셉니다. 기한이 지나고 50개 메시지 동안 언급이 없으면 보관했다가, 관련 이야기가 나오면 다시 넣습니다. 작중 날짜는 본문의 날짜 줄, 없으면 마리나라의 월드 트래커·커스텀 트래커(이름에 '날짜'·'시간'이 들어간 칸)에서 읽고, 둘 다 없으면 순서만 지킵니다.
- **최근 생활** — 누가 언제 먹고, 씻고, 자고, 약을 먹었는지. 몇 끼째인지, 몇 시간 잤는지는 프로그램이 작중 시각으로 계산합니다. 필요 없으면 끌 수 있습니다(모든 방 기본값 + 방마다 따로, [아래 참고](#최근-생활-끄기)).
- **회상** — 답변 직전에 지금 대화와 관련된 지난 장면을 골라 통째로 넣습니다. 기억 모델이 목차를 보고 고르고, 드문 낱말·원문 검색·뜻으로 찾기(임베딩)가 보조합니다. "그때 말했잖아"처럼 예전 일을 가리키는 문장은 따로 찾습니다.
- **단체방: 누가 무엇을 아는지** — 그 자리에 없던 인물은 그 일을 모르는 것으로, 짐작만 하는 인물은 짐작만 하는 것으로 기억합니다.
- **말풍선 태그 되살리기** (선택) — '합쳐서' 단체 롤플레이에서 마리나라의 원래 `<speaker="캐릭터명">대사</speaker>` 생성 지침을 보강합니다. 대사 앞에 보이는 이름표가 없어도 모델이 숨은 태그를 출력하도록 정확한 캐릭터 이름·형식·번역 포함 규칙을 전달합니다. 기존 태그와 `이름 | 대사`의 복구도 유지합니다. 지문을 분석해 화자를 추측하는 기능은 아닙니다.
- **이름 정리** — 같은 사람이 여러 이름(한국어·영어 표기, 처음에 부르던 애칭, 오타)으로 따로 저장되지 않도록 방마다 별칭 표를 둡니다. 카드와 사용자 캐릭터 이름이 기준 이름이 되고, 화자 판단·최근 생활·사실·아직 끝나지 않은 일이 모두 같은 표로 이름을 맞춥니다. 기억 서재의 **이름 정리** 탭에서 이름을 바꾸거나 합칠 수 있고(미리 보기 → 적용 → 되돌리기), 철자·소리만 비슷한 이름은 자동으로 합치지 않고 "같은 사람일 수 있음"으로 보여 줍니다.
- **기억 서재 화면** — 마리나라 개인 확장으로 넣는 화면입니다. 기억을 보고 직접 고치고, 정리와 회상을 설정하고, "이 메시지를 보내면 뭐가 떠오를지" 미리 시험할 수 있습니다. 컴퓨터 화면에서는 위쪽 막대를 끌어 창을 옮기고 모서리·가장자리를 끌어 크기를 바꿀 수 있으며(기억됨), 설정의 ‘창 위치 초기화’로 되돌립니다. 브라우저 창이 작아져 최소 크기(520×360)보다 좁아지면 저장된 위치와 크기는 무시하고 전체 화면 배치로 보여 줍니다.
- **번역 도구와 함께 (선택)** — [번역 프리셋·단어장 (기억 서재 호환)](https://github.com/tlsiddl/marinara-translation-tools)을 같이 설치하면 방의 단어장이 영어 기억의 한국어 번역과 이름 정리에 쓰이고, 저장된 응답 번역으로 한국어 낱말 회상이 됩니다. 원래의 「번역 프리셋·단어장」도 같은 방식으로 읽습니다.


최근 대화에서 이미 표현한 기억은 공유된 전제로 유지하고, 대사·지문·속마음에서 반복 설명하지 않도록 안내합니다. 재질문·정정 요청이나 새로운 상황에 필요한 재언급은 허용합니다. 실제 반복 억제 정도는 사용하는 모델과 다른 생성 지침에 따라 달라집니다.

원본 마리나라 파일은 건드리지 않습니다. 서버가 켜질 때 메모리에서만 끼어들고, 버전이 맞지 않으면 그 부분만 스스로 꺼져서 마리나라는 원래대로 돌아갑니다.

## 준비물

1. **Marinara Engine 2.4.6** (도커 서버, 그냥 실행, Termux 모두 가능)
2. **기억 정리에 쓸 모델 연결** — 마리나라에 이미 저장된 연결 중 하나를 빌려 씁니다. 답변마다 여러 번 부르니 **저렴하고 긴 글을 잘 읽는 모델**을 추천합니다(예: DeepSeek 계열).
3. (선택) **임베딩 모델** — 말을 바꿔 물어도 찾게 해 줍니다. 한국어라면 `Qwen/Qwen3-Embedding-8B`나 `BAAI/bge-m3`를 추천합니다. 마리나라 연결에 넣어 둔 임베딩 설정을 그대로 가져옵니다.

## 설치

### 1. 기억 모듈 (서버)

**도커 서버 (벌처·AWS 등)** — 서버 터미널에서:

```sh
curl -fsSL https://raw.githubusercontent.com/tlsiddl/marinara-memory-module/marinara-2.4.6/install.sh | sh
```

켜져 있는 마리나라 컨테이너를 찾아 `docker-compose.override.yml`을 만들고 다시 켭니다. 이미 그 파일이 있다면 건드리지 않고 넣을 내용을 알려 드립니다. compose를 `-f` 여러 개로 켜고 계셨다면, 앞으로도 마지막에 `-f docker-compose.override.yml`을 붙여 주세요.

**그냥 실행 (Linux·macOS)** — 마리나라 폴더에서 같은 명령을 실행한 뒤, 앞으로는 `start.sh` 대신 이렇게 켜 주세요:

```sh
bash start-memory.sh
```

**핸드폰 (Termux)** — 마리나라 폴더에서 같은 명령을 실행한 뒤 `bash start-memory.sh`로 켜 주세요(안에서 `start-termux.sh`를 부릅니다).

**Windows (베타 — 아직 실제 Windows에서 확인 중입니다)** — PowerShell을 열고 아래 명령을 실행해 주세요. 설치기가 기본 설치 위치와 바탕화면·시작 메뉴의 Marinara 바로가기를 확인합니다. 마리나라 폴더 또는 그 안의 하위 폴더에서 실행하면 해당 설치본을 우선합니다.

```powershell
irm https://raw.githubusercontent.com/tlsiddl/marinara-memory-module/marinara-2.4.6/install.ps1 | iex
```

자동으로 찾지 못하면 **폴더 선택 창**이 열립니다. `start.bat`과 `packages` 폴더가 들어 있는 마리나라 폴더를 골라 주세요. 선택 창을 사용할 수 없거나 선택한 위치가 맞지 않으면 터미널에 경로를 붙여 넣을 수 있습니다(따옴표 포함 가능). 경로 입력에서 Enter만 누르면 파일을 변경하지 않고 취소합니다. 설치본이 여러 개 발견되면 번호로 선택하며, 설치 대상 경로를 표시한 뒤 진행합니다.

직접 지정하려면 설치 명령보다 먼저 `$env:MARINARA_DIR = 'D:\Marinara-Engine'`처럼 실제 경로를 설정해 주세요.

바탕화면에 생긴 **Marinara + 기억 서재** 바로가기(또는 `start-memory.bat`)로 켜 주세요. `start.bat`이나 MarinaraLauncher로 켜면 기억 모듈 없이 켜집니다.

**설치 확인** — 마리나라 로그에 아래 줄들이 보이면 성공입니다.

```
[memory-module] v0.11.13-marinara.2.4.6.18 applied: {{기억}} macro ready
[memory-module] v0.11.13-marinara.2.4.6.18 applied: reply hook and admin API ready
```

### 2. 기억 서재 화면 (확장)

마리나라 개인 확장 관리에서 GitHub로 가져오기:

- 저장소 주소: `https://github.com/tlsiddl/marinara-memory-module`
- 브랜치: `marinara-2.4.6` (브랜치 선택을 지원하는 가져오기 화면에서)
- 파일: `deliverable/manifest.json`

브랜치 선택이 없는 화면에서는 아래 ZIP을 받아 가져와 주세요. 기본 `main` 브랜치의 확장과 혼동하지 않도록 주의해 주세요.

(또는 [deliverable/memory-library-module.personal-extension.zip](deliverable/memory-library-module.personal-extension.zip)을 받아 가져오기.) **전체 페이지 접근**을 허용하고 켜면 화면 오른쪽 아래에 책 아이콘이 생깁니다. 아이콘은 끌어서 원하는 곳으로 옮길 수 있고(두 번 누르면 처음 자리로), [확장 서랍](https://github.com/boricha417/marinara-extension-drawer)을 쓰시면 서랍 안에 자동으로 담깁니다.

### 3. 처음 설정

1. 기억 서재 → **설정** → **기억 정리에 쓸 연결**을 고르고 저장합니다.
2. 쓰는 프롬프트 프리셋에 새 섹션(역할: 시스템)을 하나 만들고 내용에 `{{기억}}`을 적습니다. 채팅 기록 바로 위에 두는 것을 추천합니다. **이걸 빠뜨리면 기억이 만들어져도 답변에 들어가지 않습니다.** (아래 '프리셋 예시' 참고)
3. 기억을 쓸 채팅방을 열고, 기억 서재 왼쪽 아래 **이 방에서 기억 사용**을 켭니다.
4. **기억 보관함** 탭에서 **이어서 정리**를 누릅니다. 처음에는 지난 대화 전체를 정리합니다.
5. (선택) **뜻으로 찾기(임베딩)** — 마리나라 연결 설정의 **시맨틱 검색(임베딩)**에 모델을 넣어 두셨다면 그대로 가져와 씁니다(임베딩 연결을 따로 정해 두셨다면 그 연결도 따라갑니다). 따로 쓰고 싶으시면 설정 → 뜻으로 찾기에서 직접 입력하실 수 있습니다. 마리나라 내장 로컬 임베딩(MiniLM)은 영어 전용이라 쓰지 않습니다.

그다음부터는 답변마다 자동으로 정리됩니다. 기억을 켠 방만 비용이 듭니다.

### 프리셋 예시

섹션을 태그로 감싸 쓰는 프리셋이라면, 앞뒤 구분자 섹션에 `<memory>` 태그를 넣어 주면 깔끔합니다. 순서는 이렇게 둡니다.

| 순서 | 섹션 | 내용 |
| --- | --- | --- |
| … | 페르소나 (마커) | |
| | 구분자 | `</persona>` 빈 줄 `<memory>` |
| | **기억** (새로 만든 섹션, 시스템) | `{{기억}}` |
| | 구분자 | `</memory>` 빈 줄 `<chat_history>` |
| | 채팅 요약 (마커) · 채팅 기록 (마커) | |

이렇게 섹션을 따로 두면 마리나라의 **프롬프트 구성** 보기에서 `MEMORY`가 독립된 칸으로 보여서, 기억이 실제로 들어갔는지와 몇 토큰인지 바로 확인할 수 있습니다.

- **처음 정리**: 메시지 500개쯤에 기억 모델 호출 150번 안팎, 1시간 남짓(저렴한 모델 기준 몇백 원 수준). 메시지 수에 거의 비례합니다.

- '처음부터 다시 정리'는 처음 정리만큼 다시 듭니다. 한 줄만 틀렸다면 화면에서 직접 고치는 것이 빠르고 무료입니다.

## 업데이트

설치할 때와 **같은 명령**을 다시 실행하고, 확장 관리에서 기억 서재도 업데이트해 주세요. 기억 데이터는 마리나라 데이터 폴더(`data/memory-module`)에 있어서 업데이트로 지워지지 않습니다.

업데이트는 새 파일을 모두 받아 확인한 뒤에 한꺼번에 바꿉니다. 중간에 받기가 실패하면 기존 버전이 그대로 남고, 바꾸기 전 버전은 `memory-module/.prev`에 보관됩니다.

**이전 버전으로 되돌리기** — 업데이트 뒤 문제가 생기면:

```sh
curl -fsSL https://raw.githubusercontent.com/tlsiddl/marinara-memory-module/marinara-2.4.6/install.sh | sh -s -- rollback
```

Windows(PowerShell):

```powershell
$env:MEMORY_MODULE_ACTION='rollback'; irm https://raw.githubusercontent.com/tlsiddl/marinara-memory-module/marinara-2.4.6/install.ps1 | iex
```

## 추가 기능 켜고 끄기

설정 → **추가 기능**에는 선택해서 쓰는 기능이 모입니다. 기능마다 **모든 방 기본값**(체크)과 **이 방**(기본값 따름 / 켜기 / 끄기)을 따로 정하고, 바꾸면 바로 서버에 저장됩니다. 서버가 이 스위치를 보고 기능을 쓸지 정하므로, 끈 방에서는 그 기능의 모델 호출이 일어나지 않습니다. 지금은 **최근 생활 기록**(처음부터 켜짐, 예전 설정 그대로 이어짐), **인물 현재 상태**, **장소 기억**, **소중한 물건**, **날짜·주기 트래커**, **제안 자동 적용**이 있습니다. 새 기능은 만들어지는 대로 이곳에 나타나며 대부분 **꺼진 채로** 시작합니다(인물 현재 상태·장소 기억·소중한 물건·날짜·주기 트래커도 꺼져 있으니 **설정 → 추가 기능**에서 켜 주세요). 예외로 **제안 자동 적용**은 **켜진 채로** 시작합니다(아래). 아직 만들어지지 않은 기능은 화면에 보이지 않습니다. 아래 **항상 켜져 있는 기능**은 모듈에 들어 있어 스위치가 없고, 예전 설정 파일에 저장된 켬/끔 값은 무시합니다.

### 항상 켜져 있는 기능 (스위치 없음)

모델을 더 부르지 않습니다. 호칭 사전·직접 고친 것 배우기는 이 방의 `<방 ID>.address.json`, 기록 충돌은 `<방 ID>.conflicts.json`(충돌이 생긴 방에만 만들어집니다)에 기록하며 백업에 들어가고 방을 지우면 함께 지워집니다.

- **호칭 사전**: 저장된 대사에서 '누가 누구를 어떻게 부르는지'(보스·애칭·'○○ 씨')를 같은 말이 두 번 이상 나온 것만 모아 **이름 정리 → 호칭 사전**에 보여 줍니다. 직접 추가·고치기·지우기와 항목별 '대사 확인에 쓰기'가 있습니다. 그 말로 불린 사람을 대사의 상대로 보고(화자가 될 수 없음) 장면에 함께 있는 사람들의 호칭이 `[호칭] A→B: 보스` 한 줄(120자 이내)로 기억에 들어갑니다.
- **직접 고친 것 배우기**: 장면 편집에서 말한 사람·들은 사람을 고치면 '이 말은 ○○를 부르는 말일까요?', '○○은 △△의 다른 이름일까요?' 같은 **제안**이 이름 정리 탭에 쌓입니다. **제안 자동 적용**이 켜져 있으면(기본) 호칭 제안은 호칭 사전에(출처 '자동 적용'), 다른 이름 제안은 이름 표에(글은 다시 쓰지 않음) 바로 들어가고 **자동으로 적용함: … [되돌리기]** 목록에 남습니다. 꺼져 있으면 예전처럼 **추가**나 **무시**를 누르기 전에는 아무것도 바뀌지 않습니다. 무시하거나 되돌린 제안은 다시 묻지도, 다시 적용하지도 않습니다. '같은 사람일 수 있음' 합치기와 기록 충돌 해결은 이 설정과 상관없이 늘 직접 고릅니다.
- **아는 사람·모르는 사람**: 알게 된 사실마다 누가 아는지(`knownBy`)와 누가 모르는지(`unaware`, 화면의 '모르는 사람')를 둡니다. 장면 정리 지침에 한 줄이 더 붙어(비밀·귓속말처럼 아는 사람이 갈리는 사실만 적게 함) 같은 호출에서 함께 읽고, 모르는 사람은 원래 있던 '모름' 기록(그 자리에 없던 사람, 나중에 알게 된 사람)을 그대로 씁니다. 비밀인데 목록이 비어 있으면 그 장면에 있던 사람 가운데 모르는 사람을 뺀 사람을 아는 사람으로 정하고, 확실하지 않으면 비워 둡니다(비어 있으면 '따로 정하지 않음'이라 아무것도 바뀌지 않습니다). 기억에는 지금 장면에 있는 사람 가운데 모르는 사람만 `… (지후는 모름)`처럼 사실 끝에 붙고(사실마다 3명까지, 사실의 주인공·사용자 캐릭터는 제외) 목록이 없는 예전 사실은 달라지지 않습니다. 알게 된 사실 화면에서 아는 사람·모르는 사람을 고칠 수 있고 직접 고친 아는 사람 목록은 자동 기록이 덮어쓰지 않습니다.
- **기록 충돌 알림**: 같은 인물에 대한 사실 가운데 서로 어긋나 보이는 것(같은 말의 긍정/부정, 같은 단위의 다른 숫자, 다른 색·왼/오른쪽, 살아 있음/죽음 등)을 글만 비교해 찾습니다(모델을 부르지 않으므로 놓치거나 틀릴 수 있음). 알게 된 사실 위에 **서로 다른 기록 N건**으로 두 사실이 나란히 나오고 **앞의 것 유지 / 뒤의 것 유지 / 둘 다 맞음 / 무시** 중에서 직접 고릅니다. 저절로 해결하지 않으며, 앞/뒤를 고르면 남기지 않은 쪽은 지우지 않고 기억 칸에서만 뺍니다. 답하기 전에는 두 사실이 그대로 들어갑니다.
- **회상 이유와 중요/빼기**: 주입 확인 탭의 '왜 이 기억이 들어갔나'에 항목마다 이유가 짧게 붙습니다(‘부두’ 언급, 뜻이 비슷함 0.71, 지금 장면에 ○○ 있음, 최근 장면, 고정, 끝나지 않은 일 등). 이유는 화면에만 보이고 기억 칸의 글·토큰에는 영향이 없습니다. 장면·챕터·사실·끝나지 않은 일 카드와 이 화면의 **중요**(정해진 크기 안에서 먼저 넣음)와 **빼기**(자동으로는 넣지 않음, 기록은 그대로)로 방마다 고르며, 같은 버튼을 다시 누르면 되돌아갑니다. `<방 ID>.recall-prefs.json`에 저장되고 백업·방 삭제·분기에 함께 처리됩니다. 직접 선택한 기억에는 빼기가 적용되지 않습니다.

### 인물 현재 상태·장소 기억·소중한 물건

셋 다 **꺼진 채로** 시작하니 설정 → **추가 기능**에서 켜 주세요. 켠 뒤에 새로 정리하는 장면부터 채워지며(이미 정리된 장면은 다시 읽지 않습니다), 장면을 정리하는 같은 모델 호출에 짧은 안내가 붙어 모델을 더 부르지는 않습니다(답이 조금 길어집니다). 방마다 `<방 ID>.state.json`, `<방 ID>.places.json`, `<방 ID>.keepsakes.json`에 기록하고 백업에 들어갑니다.

- **인물 현재 상태**: 인물마다 지금 있는 곳·옷차림·다친 곳·가진 물건·기분을 카드로 이어서 기록합니다(원문에 보인 것만, 나은 곳·잃은 물건은 빠짐). 켜 두면 지금 장면에 있는 사람의 상태가 `[지금 상태] 하린: 집무실 · 젖은 셔츠 · 왼팔 붕대` 한 줄(200자 이내)로 기억에 들어갑니다. 대사의 상대를 추정할 때는, 기록된 위치가 장면의 장소와 분명히 다른 사람을 보조로 뺍니다.
- **장소 기억**: 장소마다 모습·배치·특징(최근 12개)을 모읍니다. 지금 장면의 장소가 `[장소] 집무실: 통유리 너머 항구 · 검은 가죽 소파` 한 줄(160자 이내)로 들어갑니다. '○○의 집무실'과 '집무실'처럼 이름이 다른 곳은 자동으로 합치지 않으니, 장소 화면에서 '다른 이름'을 적거나 합쳐 주세요.
- **소중한 물건**: 선물·기념품·유품처럼 이야기에서 뜻이 있는 물건(누가 가졌는지·누가 준 것인지·담긴 뜻·간직함/남에게 줌/잃어버림/망가짐)을 물건별로 기록합니다. 평범한 소품은 적지 않고 원문에 없는 것은 지어내지 않으며, 지금 들고 있는 물건은 '인물 현재 상태'의 가진 것에 그대로 있습니다. 지금 장면에 있는 사람이 가졌거나 준 물건만 `[소중한 물건] 하린: 은반지(세아가 준 것, 약속의 징표)` 한 줄(160자 이내)로 들어갑니다. 이름이 다른 같은 물건은 자동으로 합치지 않으니 '다른 이름'이나 '합치기'를 쓰세요.
- 새 탭 **인물·장소**에서 칸마다 고칠 수 있습니다. 고친 칸은 잠겨서 자동 기록이 덮어쓰지 않고, '자동으로 되돌리기'로 풉니다.

### 날짜·주기 트래커

**꺼진 채로** 시작합니다(설정 → 추가 기능). 모델을 부르지 않고, 직접 만든 날짜 기록을 이야기 속 날짜(또는 실제 오늘)로 그때그때 세어 보여 줍니다. **인물·장소** 탭의 '날짜·주기 트래커'에서 만듭니다.

- **종류**: 며칠째(`만난 지 12일째`, 시작한 날을 1일째로 셀지 0일째로 셀지 고름) · D-day(`D-3`, `D-day`, `D+2`) · 주기(`진행 중 (2/5일째)` / `다음까지 D-9`; 주기는 N일마다 또는 N개월마다, 기간(일)을 두고, 다음 날짜는 늘 같은 주기 또는 지난 시작일들의 평균 간격으로 셈). 주기는 **오늘 시작** 버튼이나 날짜 직접 추가로 시작일을 쌓고(최근 12개) 고치거나 지울 수 있습니다.
- **대상**: 방 전체 / 한 사람 / 두 사람(이름 표의 대표 이름으로 맞춥니다). **날짜 기준**은 이야기 속 날짜(기억 모듈이 아는 작중 오늘, 모르면 '이야기 날짜 모름'이라 표시하고 기억 칸에 넣지 않음) 또는 서버의 실제 오늘입니다. 날짜는 `2024-07-16`, `24-07-16` 어느 쪽이든 됩니다.
- **기억 칸**: 트래커마다 *항상* / *관련된 사람이 지금 장면에 있을 때* / *넣지 않음*을 고르면, 해당하는 것만 `[기록] 은서·라온 사귄 지 3일째 · 은서 발정기: 진행 중 (2/5일째)` 한 줄(200자 이내, 항상인 것이 먼저, 번역 요청 없음)로 들어갑니다. 끄면 기억 칸·정리 지침은 예전과 같습니다.
- **이 장면부터**: 장면 카드의 버튼으로, 그 장면의 작중 날짜를 시작일로 하는 트래커를 새로 만들거나 기존 트래커의 시작일로 정합니다(장면에 날짜가 없으면 눌리지 않음).
- **제안**: 정리가 끝난 뒤 장면 요약·사건에 주기 트래커 이름의 낱말과 '시작/왔다/started'가 함께 나오면(사람이 정해져 있으면 그 사람 이름도, 부정문은 제외) '○○ 시작을 24-07-16으로 기록할까요?'를 띄웁니다. **제안 자동 적용**이 켜져 있으면(기본) 방금 만든 제안은 바로 시작일로 기록되고 트래커 화면의 **자동으로 적용함: … [되돌리기]**에 남습니다(되돌리면 그 날짜만 빠지고 밀려난 옛 시작일은 돌아오며, 그 제안은 무시로 남아 다시 적용되지 않습니다). 꺼져 있으면 **기록**이나 **무시**를 누르기 전에는 아무것도 바뀌지 않습니다. 같은 날짜를 두 번 묻지 않습니다. 놓치거나 틀릴 수 있으니 직접 만든 기록이 기준입니다.
- 방마다 `<방 ID>.trackers.json`에 저장되고 백업·방 삭제·분기에 함께 처리됩니다.

## 백업 내려받기·불러오기

설정 → **백업**에서 이 방의 기억(장면·사실·장부·이름 표·번역·직접 고른 기억·대사 확인 기록·호칭 사전·인물 상태·장소 기억·소중한 물건·날짜·주기 트래커·기록 충돌에 대한 답·중요/빼기 표시와 이 방의 설정)을 파일 하나(`기억백업-방이름-날짜.json`)로 내 컴퓨터에 내려받습니다. 마리나라의 채팅 메시지는 들어 있지 않습니다. **검색 색인 포함**은 크기가 커서 기본으로 빠져 있고, 빠져도 불러온 뒤 다시 만들면 됩니다.

- 한눈에 → **처음부터 다시 정리**를 한 번 누르면 확인 안내에 **먼저 백업 내려받기**가 나옵니다. 받지 않고 그냥 이어가도 됩니다.
- **백업 불러오기**: 파일을 고르면 백업의 방 이름·날짜·모듈 버전과 장면·사실·할 일 개수(백업 ↔ 지금)를 먼저 보여 줍니다. 확인하고 버튼을 **두 번** 눌러야 바뀝니다. 이 방의 기억 파일이 백업 내용으로 통째로 바뀌고(백업에 없는 파일은 지워짐), 정리 작업 중에는 불러올 수 없습니다. 백업에 검색 색인이 없으면 지금의 색인은 지우고 다음 정리 때 다시 만듭니다. 이 방의 '기억 사용' 켜짐 여부는 지금 그대로 둡니다.
- 바꾸기 전에 지금 상태를 안전 사본으로 한 번 남기고, **불러오기 되돌리기**로 되돌릴 수 있습니다(가장 최근 한 번만, 쓰고 나면 사라집니다).
- 다른 방에서 받은 백업은 **다른 방의 백업을 이 방에 적용**을 체크해야 불러옵니다. 메시지 번호와 ID는 그대로이므로 이 방의 메시지와 맞지 않을 수 있습니다.
- 파일은 50MB까지, 이 모듈이 만든 형식만 받습니다. 내용이 고쳐졌거나 모르는 항목이 있으면 거부합니다.

## 최근 생활 끄기

식사·씻기·잠·약 기록이 필요 없는 방이라면 끌 수 있습니다.

- 설정 → **추가 기능** → **최근 생활 기록 (모든 방 기본값)**: 처음에는 켜져 있습니다(예전과 같음).
- 설정 → **추가 기능** → **이 방의 최근 생활 기록**: *기본값 따름* / *켜기* / *끄기*. 기본값을 꺼 두고 몇 방만 켜거나, 그 반대로 쓸 수 있습니다.

꺼진 방에서는:

- 새 메시지에서 생활을 읽지 않습니다. 장부 정리 요청에서 생활 기록 지침을 빼고 보내므로 그 몫의 기억 모델 호출과 토큰이 들지 않고, 식사 내용 정리 호출도 하지 않습니다(장부의 다른 내용은 그대로 정리합니다).
- 기억 칸(`{{기억}}`)에 `[최근 생활]`을 넣지 않습니다.
- **이미 있는 기록은 지우지 않습니다.** 최근 생활 탭에서 계속 보고 고칠 수 있고, 탭 위에 꺼져 있다는 안내와 **이 방에서 켜기** 버튼이 보입니다.

다시 켜면 남아 있던 기록이 그대로 보이고 기억 칸에도 다시 들어가며, **그 뒤 새 메시지부터** 이어서 기록합니다. 꺼져 있던 동안 정리한 메시지는 자동으로 다시 읽지 않습니다(추가 비용이 들지 않게). 최근 생활 탭에 그 구간(예: "메시지 120~180번")이 표시되고, 그 구간까지 채우려면 한눈에 → **처음부터 다시 정리**를 눌러 주세요(전체를 다시 읽어 그만큼 비용이 듭니다). 설정은 서버의 기억 모듈 설정에 저장되어 어느 기기에서 열어도 같습니다.

## 기억 언어 (한국어 / 영어)

설정 → **기억 언어**에서 정합니다.

언어는 두 가지를 따로 고릅니다.

| | 정리할 언어 | 넣을 언어 |
|---|---|---|
| 무엇 | 기억 서재에 **저장되는** 언어 | 답변 만들 때 프롬프트에 **넣는** 언어 |
| 기본 | 채팅 언어로 | 정리한 언어 그대로(번역 없음) |
| 바꾸면 | 새로 정리되는 기억부터 그 언어로 저장 | 저장된 기억은 그대로, 넣을 때만 번역 |
| 다시 정리 | 기존 기억까지 바꾸려면 필요 | **필요 없음** |

**넣을 언어만 바꾸면** 저장된 기억(장면·사실·장부)은 그대로 두고 프롬프트에 넣는 글만 고른 언어로 바꿉니다. 장면이 100개 넘게 쌓인 방도 설정만 바꾸면 됩니다.

- **기억을 정리할 언어** — 기본은 *채팅 언어로*입니다. *영어로*를 고르면 한국어 방도 새로 정리되는 기억부터 영어로 저장하고(대사 인용과 이름은 원문 그대로), 기억 서재 화면에서는 한국어 번역을 함께 보여 줍니다. 이미 한국어로 정리된 기억은 그대로 두고 넣을 때 영어로 번역하므로 바로 써도 됩니다. 전부 영어로 저장하려면 한눈에 → *처음부터 다시 정리*를 눌러 주세요(직접 고친 장면은 사라집니다). 한국어 방에서 영어로 정리하면 '빠른 방식' 회상(낱말 맞추기)은 덜 걸리고, 기본 회상(모델이 고르기)과 뜻으로 찾기는 그대로 동작합니다.
- **기억을 넣을 언어** — 기본은 *정리한 언어 그대로*입니다(번역 없음). *영어*를 고르면 한국어 방의 기억도 영어로 번역해서 넣습니다. 대사 인용과 이름은 늘 원문 그대로입니다.
- **번역에 쓸 연결** — 기본은 기억 정리 연결입니다. 더 저렴한 모델을 따로 고를 수 있습니다. 번역은 줄마다 한 번만 하고 저장해 다시 씁니다.
- **영어 대사도 한국어로 보기** — 기억 서재 화면에서 영어 대사 아래에 한국어 번역을 함께 보여 줍니다.

언어를 바꾸고 저장하면 그 자리에서 기억을 켠 방들의 기억을 뒤에서 미리 번역해 둡니다. 설정 화면에 "옮기는 중 120 / 340줄" → "준비가 끝났습니다"로 진행이 보입니다(창을 닫아도 서버에서 계속합니다). 끝나기 전에 답변을 만들면 아직 번역되지 않은 줄만 원래 언어로 들어가고, 기억이 빠지지는 않습니다. 그 뒤 새로 정리되는 기억도 정리가 끝날 때마다 이어서 번역합니다. 다시 *정리한 언어 그대로*로 돌리면 번역 없이 원래대로 들어갑니다.

영어로 진행되는 방은 기억 자체를 영어로 정리하고, 기억 서재 화면에서 한국어 번역을 함께 보여 줍니다.

## 자주 묻는 질문

**확장 서랍 같은 다른 확장과 같이 쓸 수 있나요?**
네. 기억 서재를 여는 버튼은 `body` 바로 아래의 `<button id="memory-module-launcher" data-drawer-launcher>`입니다. 서랍 확장이 이 버튼을 담아 두고 눌러서(click) 열 수 있고, Esc로 닫힙니다. 스크립트에서는 `window.memoryModuleLibrary.open()` / `.close()` / `.toggle()`을 쓰셔도 됩니다.

**DeepSeek를 기억용 연결로 써도 되나요?**
됩니다. DeepSeek 공식 API는 기본으로 생각(추론) 모드가 켜져 있어 긴 정리에서 답이 비거나 잘릴 수 있는데, 기억 모듈이 기억 정리·번역 요청에서는 생각 모드를 끄고 보냅니다(롤플레이 답변에는 영향 없음). 다른 사이트를 거쳐 쓰는 생각 모델에서 "빈 답" 오류가 나면 연결 설정에서 생각 모드를 끄거나 다른 모델을 골라 주세요.

**마리나라 기본 '활성 요약'과 같이 써도 되나요?**
하는 일이 겹쳐서 같은 내용이 두 번 들어갑니다. 기억 모듈을 켠 방에서는 끄는 것을 추천합니다(요약이 숨긴 메시지도 기억 모듈은 계속 읽습니다).

**답변이 기억을 늘어놓듯 과거를 설명해요.**
설정 → **회상 양**을 **적게**로, **캐릭터가 지난 일을 먼저 꺼내는 정도**를 **은은하게**로 내려 보세요.

**캐릭터가 지난 일을 먼저 꺼내지 않아요.**
설정 → **캐릭터가 지난 일을 먼저 꺼내는 정도**를 **적극적으로**로 올려 보세요(기본은 '자연스럽게'). 어느 쪽이든 지난 일을 줄줄이 설명하지는 않게 합니다.

**예전 일을 물었는데 기억을 못 끌어와요.**
주입 확인 탭의 **회상 시험**에 그 메시지를 넣어 보세요. 어떤 장면이 왜 떠오르는지(또는 안 떠오르는지) 보입니다. 임베딩을 켜 두면 말을 바꿔 물어도 잘 찾습니다.

**작중 날짜를 못 읽어요.**
본문 첫 줄의 `24-10-18 (금) | 14:00` 같은 날짜 줄이나, 마리나라 월드 트래커의 날짜·시간 칸을 읽습니다. 커스텀 트래커를 쓰신다면 칸 이름에 '날짜'·'시간'·'date'·'time'을 넣어 주세요. `2024년 10월 18일`, `10월 18일 오후 3시`, `24.10.18 21:05` 같은 형식을 읽고, '3일차'처럼 날짜가 아닌 표기는 순서만 지킵니다.

**캐릭터 이름이 처음 부르던 애칭(또는 다른 표기)으로 굳었어요.**
기억 서재 → **이름 정리**에서 지금 쓰인 이름을 고르고 기준 이름(카드의 전체 이름 등)과 글 속에 쓸 이름(전체 이름이 어색하면 이름만)을 정한 뒤 **미리 보기**를 누르세요. 대사의 말한 사람·들은 사람, 장면·사건, 사실, 아직 끝나지 않은 일, 최근 생활, 챕터마다 몇 곳이 바뀌는지와 예시가 보이고, 확인해야 적용됩니다. 원문 대사의 글자는 바꾸지 않고, 바꾼 기록은 직접 고친 것으로 표시되어 자동 정리가 되돌리지 않습니다. 옛 이름은 별칭으로 남아 다음 정리부터 같은 사람으로 봅니다. 정리 중에는 적용할 수 없고, 마지막 바꾸기는 되돌릴 수 있습니다.

**최근 생활에 같은 사람이 영어 이름·한국어 이름으로 따로 쌓여요.**
이름 정리 탭의 **이미 저장된 중복**(별칭·조사 붙은 이름처럼 규칙으로 같은 사람)은 한 번에 합칠 수 있고, **같은 사람일 수 있음**(철자·소리가 비슷할 뿐인 이름)은 하나씩 확인해서 합치거나 '다른 사람'으로 둘 수 있습니다. 합친 이름은 별칭이 되어 이후 새 기록은 한 사람으로 저장됩니다.

**기억 내용이 틀렸어요.**
장면·사실·장부·최근 생활 모두 기억 서재에서 직접 고칠 수 있고, 직접 고친 내용은 리롤해도 유지됩니다.

**화면에 '이 마리나라 버전에서는 … 기능이 꺼져 있습니다'가 떠요.**
마리나라가 업데이트되어 기억 모듈이 끼어드는 자리가 바뀐 것입니다. 마리나라는 정상 작동합니다. 기억 모듈 업데이트를 기다려 주세요.

**제 대화는 어디로 가나요?**
기억 정리를 위해 대화 내용이 **설정에서 고른 기억용 연결**(과 임베딩 모델)로 보내집니다. 그 외 다른 곳으로는 보내지 않습니다. 정리된 기억은 내 마리나라 서버의 데이터 폴더에만 저장됩니다.

## 도커 서버 명령어 (선택)

도커 설치에서는 짧은 명령 `mm`이 생깁니다.

```sh
mm list        # 채팅방 목록과 ID
mm use <ID>    # 앞으로 쓸 방 정하기
mm status      # 진행 상황
mm report      # 상태와 기억 전체를 한 번에 (홈 폴더의 memory-report.txt에도 저장)
```
