# 기억 서재 — 마리나라 엔진용 장기 기억 모듈

긴 롤플레이(수백~수천 턴)에서 캐릭터가 지난 일을 **사람처럼** 기억하게 해 주는 기억 모듈입니다.
지난 대화를 장면·사실·약속·감정으로 정리해 두었다가, 답변을 만들 때마다 지금 필요한 기억을 골라 프롬프트에 넣어 줍니다.

> **비공식 모듈입니다.** Marinara Engine 및 Pasta-Devs와 관련이 없고, 그쪽의 검토나 지원을 받지 않습니다.
> Marinara Engine **2.4.6 전용 호환 브랜치**입니다. 공식 2.4.6 서버를 직접 빌드해 실행하고 장부·장면·회상·말풍선 태그·기억 언어 흐름을 확인했습니다. [검증 범위](COMPATIBILITY.md)를 확인해 주세요.

지금 버전: **v0.11.4-marinara.2.4.6.9 (호환 베타)** · 변경 내역은 [CHANGELOG.md](CHANGELOG.md)

## 무엇을 하나요

- **분기 기억 이어받기** — 업데이트 후 새 분기를 만들면 원본에서 이미 정리된 기억과 방별 사용 설정을 분기 지점까지 자동으로 넘깁니다. 직접 고친 기억도 유지되며, 이후에는 방마다 독립적으로 갱신됩니다. 분기 지점을 걸치는 장면·장부 묶음은 다시 읽습니다. 아주 오래전 분기라 장부 복구 기록이 없으면 장면 기억은 넘기고 장부는 다시 정리합니다. 업데이트 전에 만든 분기는 자동으로 덮어쓰지 않습니다.
- **장면 기억** — 모델이 더 이상 원문으로 보지 못하는 지난 대화를 장면 단위로 정리합니다. 장면마다 작중 시간·장소·날씨·요약, 실제 대사(원문과 번역), 인물마다 그 장면을 얼마나 기억하는지(다 기억함 / 흐릿함 / 기억 못 함)가 남습니다.
- **챕터와 큰 흐름** — 오래된 장면은 이야기 흐름이 끝나는 곳에서 끊어 챕터로 묶고, 챕터가 많이 쌓이면 오래된 챕터 여러 개를 다시 '큰 흐름'(A1, A2 …)으로 묶습니다. '지난 이야기 흐름'에는 큰 흐름이 맨 앞에 늘 들어가고 최근 챕터가 이어서 들어가, 아주 긴 이야기도 처음부터 지금까지의 줄기가 정해진 길이 안에 들어갑니다.
- **알게 된 사실** — 인물의 설정·과거·관계처럼 오래 가는 사실. 같은 주제로 쌓이면 자동으로 합칩니다.
- **아직 끝나지 않은 일** — 약속, 풀리지 않은 감정(원인과 풀리려면 필요한 것), 비밀과 단서, 기간이 있는 상태(휴가, 몸살 등), 미해결 일.
- **기한** — 마감·약속 날짜가 있는 일은 기한이 가까운 것부터 매번 넣고 "D-2", "3일 지남"처럼 작중 날짜로 셉니다. 기한이 지나고 50개 메시지 동안 언급이 없으면 보관했다가, 관련 이야기가 나오면 다시 넣습니다. 작중 날짜는 본문의 날짜 줄, 없으면 마리나라의 월드 트래커·커스텀 트래커(이름에 '날짜'·'시간'이 들어간 칸)에서 읽고, 둘 다 없으면 순서만 지킵니다.
- **최근 생활** — 누가 언제 먹고, 씻고, 자고, 약을 먹었는지. 몇 끼째인지, 몇 시간 잤는지는 프로그램이 작중 시각으로 계산합니다.
- **회상** — 답변 직전에 지금 대화와 관련된 지난 장면을 골라 통째로 넣습니다. 기억 모델이 목차를 보고 고르고, 드문 낱말·원문 검색·뜻으로 찾기(임베딩)가 보조합니다. "그때 말했잖아"처럼 예전 일을 가리키는 문장은 따로 찾습니다.
- **단체방: 누가 무엇을 아는지** — 그 자리에 없던 인물은 그 일을 모르는 것으로, 짐작만 하는 인물은 짐작만 하는 것으로 기억합니다.
- **말풍선 태그 되살리기** (선택) — '합쳐서' 단체 롤플레이에서 마리나라의 원래 `<speaker="캐릭터명">대사</speaker>` 생성 지침을 보강합니다. 대사 앞에 보이는 이름표가 없어도 모델이 숨은 태그를 출력하도록 정확한 캐릭터 이름·형식·번역 포함 규칙을 전달합니다. 기존 태그와 `이름 | 대사`의 복구도 유지합니다. 지문을 분석해 화자를 추측하는 기능은 아닙니다.
- **기억 서재 화면** — 마리나라 개인 확장으로 넣는 화면입니다. 기억을 보고 직접 고치고, 정리와 회상을 설정하고, "이 메시지를 보내면 뭐가 떠오를지" 미리 시험할 수 있습니다.


최근 대화에서 이미 표현한 기억은 공유된 전제로 유지하고, 대사·지문·속마음에서 반복 설명하지 않도록 안내합니다. 재질문·정정 요청이나 새로운 상황에 필요한 재언급은 허용합니다. 실제 반복 억제 정도는 사용하는 모델과 다른 생성 지침에 따라 달라집니다.

원본 마리나라 파일은 건드리지 않습니다. 서버가 켜질 때 메모리에서만 끼어들고, 버전이 맞지 않으면 그 부분만 스스로 꺼져서 마리나라는 원래대로 돌아갑니다.

## 준비물

1. **Marinara Engine 2.4.6** (도커 서버, 그냥 실행, Termux 모두 가능)
2. **기억 정리에 쓸 모델 연결** — 마리나라에 이미 저장된 연결 중 하나를 빌려 씁니다. 답변마다 여러 번 부르니 **저렴하고 긴 글을 잘 읽는 모델**을 추천합니다(예: DeepSeek 계열).

## 설치

### 1. 기억 모듈 (서버)

**도커 서버 (벌처·AWS 등)** — 서버 터미널에서:

```sh
curl -fsSL https://raw.githubusercontent.com/tlsiddl/marinara-memory-module/marinara-2.4.6/install.sh | sh
```

켜져 있는 마리나라 컨테이너를 찾아 `docker-compose.override.yml`을 만들고 다시 켭니다. 이미 그 파일이 있다면 건드리지 않고 넣을 내용을 알려 드립니다. compose를 `-f` 여러 개로 켜고 계셨다면, 앞으로도 마지막에 `-f docker-compose.override.yml`을 붙여 주세요.

**그냥 실행 (Linux·macOS)** — 마리나라 폴더에서 같은 명령을 실행한 뒤, 앞으로는 `start.sh` 대신 이렇게 켜 주세요:

```sh
bash start-memory.sh
```

**핸드폰 (Termux)** — 마리나라 폴더에서 같은 명령을 실행한 뒤 `bash start-memory.sh`로 켜 주세요(안에서 `start-termux.sh`를 부릅니다).

**Windows (베타 — 아직 실제 Windows에서 확인 중입니다)** — PowerShell을 열고 아래 명령을 실행해 주세요. 설치기가 기본 설치 위치와 바탕화면·시작 메뉴의 Marinara 바로가기를 확인합니다. 마리나라 폴더 또는 그 안의 하위 폴더에서 실행하면 해당 설치본을 우선합니다.

```powershell
irm https://raw.githubusercontent.com/tlsiddl/marinara-memory-module/marinara-2.4.6/install.ps1 | iex
```

자동으로 찾지 못하면 **폴더 선택 창**이 열립니다. `start.bat`과 `packages` 폴더가 들어 있는 마리나라 폴더를 골라 주세요. 선택 창을 사용할 수 없거나 선택한 위치가 맞지 않으면 터미널에 경로를 붙여 넣을 수 있습니다(따옴표 포함 가능). 경로 입력에서 Enter만 누르면 파일을 변경하지 않고 취소합니다. 설치본이 여러 개 발견되면 번호로 선택하며, 설치 대상 경로를 표시한 뒤 진행합니다.

직접 지정하려면 설치 명령보다 먼저 `$env:MARINARA_DIR = 'D:\Marinara-Engine'`처럼 실제 경로를 설정해 주세요.

바탕화면에 생긴 **Marinara + 기억 서재** 바로가기(또는 `start-memory.bat`)로 켜 주세요. `start.bat`이나 MarinaraLauncher로 켜면 기억 모듈 없이 켜집니다.

**설치 확인** — 마리나라 로그에 아래 줄들이 보이면 성공입니다.

```
[memory-module] v0.11.4-marinara.2.4.6.9 applied: {{기억}} macro ready
[memory-module] v0.11.4-marinara.2.4.6.9 applied: reply hook and admin API ready
```

### 2. 기억 서재 화면 (확장)

마리나라 개인 확장 관리에서 GitHub로 가져오기:

- 저장소 주소: `https://github.com/tlsiddl/marinara-memory-module`
- 브랜치: `marinara-2.4.6` (브랜치 선택을 지원하는 가져오기 화면에서)
- 파일: `deliverable/manifest.json`

브랜치 선택이 없는 화면에서는 아래 ZIP을 받아 가져와 주세요. 기본 `main` 브랜치의 확장과 혼동하지 않도록 주의해 주세요.

(또는 [deliverable/memory-library-module.personal-extension.zip](deliverable/memory-library-module.personal-extension.zip)을 받아 가져오기.) **전체 페이지 접근**을 허용하고 켜면 화면 오른쪽 아래에 책 아이콘이 생깁니다. 아이콘은 끌어서 원하는 곳으로 옮길 수 있고(두 번 누르면 처음 자리로), [확장 서랍](https://github.com/boricha417/marinara-extension-drawer)을 쓰시면 서랍 안에 자동으로 담깁니다.

### 3. 처음 설정

1. 기억 서재 → **설정** → **기억 정리에 쓸 연결**을 고르고 저장합니다.
2. 쓰는 프롬프트 프리셋에 새 섹션(역할: 시스템)을 하나 만들고 내용에 `{{기억}}`을 적습니다. 채팅 기록 바로 위에 두는 것을 추천합니다. **이걸 빠뜨리면 기억이 만들어져도 답변에 들어가지 않습니다.** (아래 '프리셋 예시' 참고)
3. 기억을 쓸 채팅방을 열고, 기억 서재 왼쪽 아래 **이 방에서 기억 사용**을 켭니다.
4. **기억 보관함** 탭에서 **이어서 정리**를 누릅니다. 처음에는 지난 대화 전체를 정리합니다.
5. (선택) **뜻으로 찾기(임베딩)** — 마리나라 연결 설정의 **시맨틱 검색(임베딩)**에 모델을 넣어 두셨다면 그대로 가져와 씁니다(임베딩 연결을 따로 정해 두셨다면 그 연결도 따라갑니다). 따로 쓰고 싶으시면 설정 → 뜻으로 찾기에서 직접 입력하실 수 있습니다. 마리나라 내장 로컬 임베딩(MiniLM)은 영어 전용이라 쓰지 않습니다.

그다음부터는 답변마다 자동으로 정리됩니다. 기억을 켠 방만 비용이 듭니다.

### 프리셋 예시

섹션을 태그로 감싸 쓰는 프리셋이라면, 앞뒤 구분자 섹션에 `<memory>` 태그를 넣어 주면 깔끔합니다. 순서는 이렇게 둡니다.

| 순서 | 섹션 | 내용 |
| --- | --- | --- |
| … | 페르소나 (마커) | |
| | 구분자 | `</persona>` 빈 줄 `<memory>` |
| | **기억** (새로 만든 섹션, 시스템) | `{{기억}}` |
| | 구분자 | `</memory>` 빈 줄 `<chat_history>` |
| | 채팅 요약 (마커) · 채팅 기록 (마커) | |

이렇게 섹션을 따로 두면 마리나라의 **프롬프트 구성** 보기에서 `MEMORY`가 독립된 칸으로 보여서, 기억이 실제로 들어갔는지와 몇 토큰인지 바로 확인할 수 있습니다.

## 비용과 시간 (대략)

- **처음 정리**: 메시지 500개쯤에 기억 모델 호출 150번 안팎, 1시간 남짓(저렴한 모델 기준 몇백 원 수준). 메시지 수에 거의 비례합니다.
- **평소**: 답변 한 번에 기억 모델 호출 1~2번(장부 갱신, 회상 고르기). 가끔 장면·챕터 정리.
- **프롬프트에 들어가는 기억**: 보통 1만~1만 5천 토큰. 설정의 **회상 양**(적게/보통/많이)으로 조절합니다.
- '처음부터 다시 정리'는 처음 정리만큼 다시 듭니다. 한 줄만 틀렸다면 화면에서 직접 고치는 것이 빠르고 무료입니다.

## 업데이트

설치할 때와 **같은 명령**을 다시 실행하고, 확장 관리에서 기억 서재도 업데이트해 주세요. 기억 데이터는 마리나라 데이터 폴더(`data/memory-module`)에 있어서 업데이트로 지워지지 않습니다.

업데이트는 새 파일을 모두 받아 확인한 뒤에 한꺼번에 바꿉니다. 중간에 받기가 실패하면 기존 버전이 그대로 남고, 바꾸기 전 버전은 `memory-module/.prev`에 보관됩니다.

**이전 버전으로 되돌리기** — 업데이트 뒤 문제가 생기면:

```sh
curl -fsSL https://raw.githubusercontent.com/tlsiddl/marinara-memory-module/marinara-2.4.6/install.sh | sh -s -- rollback
```

Windows(PowerShell):

```powershell
$env:MEMORY_MODULE_ACTION='rollback'; irm https://raw.githubusercontent.com/tlsiddl/marinara-memory-module/marinara-2.4.6/install.ps1 | iex
```

## 끄기·지우기

- **잠깐 끄기**: 방마다 기억 서재에서 **이 방에서 기억 사용**을 끕니다.
- **모듈 끄기**: 도커는 `docker-compose.override.yml`에서 기억 모듈 두 줄을 지우거나 파일을 지우고 `docker compose up -d`. 그냥 실행은 `start.sh`로 켜면 됩니다.
- **완전히 지우기**: 위처럼 끈 뒤 마리나라 폴더의 `memory-module` 폴더와 데이터 폴더의 `memory-module` 폴더를 지웁니다.

## 기억 언어 (한국어 / 영어)

설정 → **기억 언어**에서 정합니다.

**한 줄 요약: 저장은 그대로, 넣을 때만 번역합니다.** 기억 서재에 저장된 기억(장면·사실·장부)은 정리된 언어 그대로 두고, 답변을 만들 때 프롬프트에 넣는 글만 고른 언어로 바꿉니다. 그래서 언어를 바꿔도 **다시 정리할 필요가 없습니다**. 장면이 100개 넘게 쌓인 방도 설정만 바꾸면 됩니다.

- **기억을 넣을 언어** — 기본은 *채팅 언어와 같게*입니다. 한국어로 진행되는 방은 한국어로, 영어로 진행되는 방은 영어로 정리하고 그대로 넣습니다(번역 없음). *영어*를 고르면 한국어 방의 기억도 영어로 번역해서 넣습니다. 대사 인용과 이름은 늘 원문 그대로입니다.
- **번역에 쓸 연결** — 기본은 기억 정리 연결입니다. 더 저렴한 모델을 따로 고를 수 있습니다. 번역은 줄마다 한 번만 하고 저장해 다시 씁니다.
- **영어 대사도 한국어로 보기** — 기억 서재 화면에서 영어 대사 아래에 한국어 번역을 함께 보여 줍니다.

언어를 바꾸고 저장하면 그 자리에서 기억을 켠 방들의 기억을 뒤에서 미리 번역해 둡니다. 설정 화면에 "옮기는 중 120 / 340줄" → "준비가 끝났습니다"로 진행이 보입니다(창을 닫아도 서버에서 계속합니다). 끝나기 전에 답변을 만들면 아직 번역되지 않은 줄만 원래 언어로 들어가고, 기억이 빠지지는 않습니다. 그 뒤 새로 정리되는 기억도 정리가 끝날 때마다 이어서 번역합니다. 다시 *채팅 언어와 같게*로 돌리면 번역 없이 원래대로 들어갑니다.

영어로 진행되는 방은 기억 자체를 영어로 정리하고, 기억 서재 화면에서 한국어 번역을 함께 보여 줍니다.

## 자주 묻는 질문

**마리나라 기본 '활성 요약'과 같이 써도 되나요?**
하는 일이 겹쳐서 같은 내용이 두 번 들어갑니다. 기억 모듈을 켠 방에서는 끄는 것을 추천합니다(요약이 숨긴 메시지도 기억 모듈은 계속 읽습니다).

**답변이 기억을 늘어놓듯 과거를 설명해요.**
설정 → **회상 양**을 **적게**로, **캐릭터가 지난 일을 먼저 꺼내는 정도**를 **은은하게**로 내려 보세요.

**캐릭터가 지난 일을 먼저 꺼내지 않아요.**
설정 → **캐릭터가 지난 일을 먼저 꺼내는 정도**를 **적극적으로**로 올려 보세요(기본은 '자연스럽게'). 어느 쪽이든 지난 일을 줄줄이 설명하지는 않게 합니다.

**예전 일을 물었는데 기억을 못 끌어와요.**
주입 확인 탭의 **회상 시험**에 그 메시지를 넣어 보세요. 어떤 장면이 왜 떠오르는지(또는 안 떠오르는지) 보입니다. 임베딩을 켜 두면 말을 바꿔 물어도 잘 찾습니다.

**작중 날짜를 못 읽어요.**
본문 첫 줄의 `24-10-18 (금) | 14:00` 같은 날짜 줄이나, 마리나라 월드 트래커의 날짜·시간 칸을 읽습니다. 커스텀 트래커를 쓰신다면 칸 이름에 '날짜'·'시간'·'date'·'time'을 넣어 주세요. `2024년 10월 18일`, `10월 18일 오후 3시`, `24.10.18 21:05` 같은 형식을 읽고, '3일차'처럼 날짜가 아닌 표기는 순서만 지킵니다.

**기억 내용이 틀렸어요.**
장면·사실·장부·최근 생활 모두 기억 서재에서 직접 고칠 수 있고, 직접 고친 내용은 리롤해도 유지됩니다.

**화면에 '이 마리나라 버전에서는 … 기능이 꺼져 있습니다'가 떠요.**
마리나라가 업데이트되어 기억 모듈이 끼어드는 자리가 바뀐 것입니다. 마리나라는 정상 작동합니다. 기억 모듈 업데이트를 기다려 주세요.

**제 대화는 어디로 가나요?**
기억 정리를 위해 대화 내용이 **설정에서 고른 기억용 연결**(과 임베딩 모델)로 보내집니다. 그 외 다른 곳으로는 보내지 않습니다. 정리된 기억은 내 마리나라 서버의 데이터 폴더에만 저장됩니다.

## 도커 서버 명령어 (선택)

도커 설치에서는 짧은 명령 `mm`이 생깁니다.

```sh
mm list        # 채팅방 목록과 ID
mm use <ID>    # 앞으로 쓸 방 정하기
mm status      # 진행 상황
mm report      # 상태와 기억 전체를 한 번에 (홈 폴더의 memory-report.txt에도 저장)
```
